# My Static Website Hosted on GitHub Pages

This is a simple static website created and hosted on **GitHub Pages**.

## Project Overview

This project demonstrates how to create a basic static website and host it for free using **GitHub Pages**. It includes an `index.html` file and a `style.css` file for styling.

## Website URL

The website is live and can be accessed at:

 https://bharadwaj-av.github.io/my-static-website-Day-6/

## Project Structure

- `index.html`: The main HTML file containing the content of the website.
- `style.css`: The CSS file used to style the website.

## Features

- A **header** (`<h1>`) with a greeting message.
- A **paragraph** (`<p>`) explaining that this is my first website using GitHub Pages.
- Custom **styling** applied using the `style.css` file.

## How to View the Website

1. Clone this repository to your local machine or visit the live website link.
2. Open the `index.html` file in a browser to view the content.
3. For the live version, visit the GitHub Pages URL provided above.

## Customization

Feel free to modify the `index.html` and `style.css` files to customize the content and design of the website.
